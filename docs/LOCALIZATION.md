# QuotaDock 언어 지원 0.6.9

0.4.3부터 `연결·설정 → 언어 / Language`에 시스템 설정 따름·한국어·English를 제공한다. 언어는 이 앱의 `displayLanguage` 설정에 보관하고 다시 실행해도 유지한다. 시스템 설정은 한국어 계열이면 한국어, 그 외에는 영어를 선택한다. macOS 전역 언어 설정을 바꾸지 않는다.

메뉴·대시보드·구독 편집·연결·혜택·관측 기록·앱 생성 오류·접근성 이름을 표시할 때 언어팩을 적용한다. 날짜·금액은 선택한 표시 언어의 locale로 포맷하되 실제 날짜·타임존·통화 코드는 바꾸지 않는다. macOS가 제공하는 메뉴·오류 메시지와 일부 네이티브 날짜 입력 컨트롤은 시스템 언어를 따를 수 있다.

## 데이터와 알림

Provider ID, 계정 범위·해시, 플랜·quota ID, 저장된 초기화·메모·이벤트 원문은 번역해서 저장하지 않는다. 기존 한국어 이벤트도 표시 시 번역한다. 미제공을 0으로 만들지 않고, 이전 값·직접 기록·복구 미확정 의미를 영어에서도 유지한다. 알 수 없는 서버/사용자 문구는 추정 번역하지 않고 원문을 보존한다.

새 시스템 알림 내용에는 선택한 언어를 적용한다. 언어를 바꾸면 미래 검토 예약을 같은 기록 ID와 같은 시각으로 다시 등록하도록 한다. 0.6.1부터 로컬 임시 서명 빌드에서도 macOS 알림 권한을 요청할 수 있다. 배너 표시는 Mac의 알림·집중 모드·화면 공유 설정에 영향을 받으며 Developer ID·공증은 외부 배포 단계에서 별도로 검토한다. 앱 내부 문구·예약 코드 검사와 다른 Mac의 실제 배너 수신 확인은 구분한다.

## 언어팩 유지

`Sources/QuotaPilot/Resources/ko.json`과 `en.json`에 기존 한국어 소스 문구와 대응 문구를 보관한다. 동적인 문구는 `{0}`, `{1}` 자리 표시자를 사용하고 `argumentTypes`에서 숫자 단위를 `integer`로 지정해 무관한 단어가 번역 패턴에 걸리지 않게 한다. 키와 자리 표시자는 두 팩에서 맞아야 한다.

기존 저장 문자열 호환을 위해 정확한 문구·숫자/시간 템플릿·기존 연결 문구를 표시 단계에서 처리한다. 한국어 UX 문구를 바꿀 때는 언어팩도 함께 갱신해야 한다. 장기적으로 큰 문구 개편을 진행하면 표시 키를 의미 기반으로 분리할 수 있으나, 현재 저장 데이터의 문자열을 바꾸거나 초기화하지 않는다.

```sh
python3 scripts/check-localizations.py
zsh scripts/test.sh
zsh scripts/build-app.sh
```

SwiftPM 리소스 번들을 앱의 `Contents/Resources`에 함께 복사하고 코드 서명한다. 설치한 앱의 번들을 우선 읽고 개발/테스트 환경에서만 SwiftPM의 모듈 번들을 대체 경로로 사용한다. [SwiftPM 리소스 설명](https://docs.swift.org/package-manager/PackageDescription/PackageDescription.html)에 따른 패키지 리소스 구성이다. 번들 없이 언어만 전환한 빌드를 배포하지 않는다.

새 언어를 추가할 때는 리소스와 선택 항목·locale를 함께 등록하고 숫자 단위·날짜·긴 문구·알림을 검증한다. 알림이나 날짜를 한국어로 남긴 채 버튼만 번역하는 것을 언어 지원 완료로 취급하지 않는다.

0.4.4 UX 보강에서 한국어·영어 각 466개 문구를 포함한다. 알림 목록과 명시적인 읽음 처리, 연결 상태·연결 해제 동작, 혜택 만료를 번역했다. 예전 이벤트 표시 호환을 위해 지금 화면에서 쓰지 않는 이전 키도 유지한다.

0.4.6은 한국어·영어 각 511개 문구를 포함하며 기록 종류·AI 필터·표시 개수·토큰 취소 및 처리 범위를 번역한다. 소스의 430개 템플릿 누락 및 자리 표시자 일치 검사에 통과했다.

0.4.7은 한국어·영어 각 532개 문구와 소스 420개 템플릿을 검사했다. 구독 날짜·미입력·자동 조회 미제공과 시스템 알림 지원 상태를 번역했다. 이전 저장 문구의 호환 키는 유지한다.

0.4.8은 한국어·영어 각각 583개 문구와 소스 466개 템플릿을 검사했다. 웹 날짜 조회·별도 인증 창·계정 확인·날짜만 제공되는 상태를 번역하고, 공식 웹의 갱신 문구는 번역하지 않은 원문으로 보여준다.

0.4.10은 한국어·영어 각각 611개 키와 소스 465개 템플릿을 검사했다. 날짜 수동 입력 제거·계정 확인 즉시 반영·Grok Build 토큰 범위를 두 언어에 반영했다. 사용하지 않는 과거 키는 이전 표시 호환을 위해 유지한다.

0.4.11은 한국어·영어 618개 키와 소스 451개 템플릿을 검사했다. 개발용 배지와 중복 안내를 두 언어에서 함께 제거했다. 과거 저장 기록의 번역 호환을 위해 사용하지 않는 이전 키는 보존한다.

## 0.5.0

QuotaDock 이름과 상단바 설정의 한국어·영어 문구를 추가했다. 459개 소스 템플릿, 언어별 638개 항목을 검사했다. 기간 숨김은 서비스명·모델명·접근성 설명을 제거하지 않는다.
