# QuotaDock 무료 베타 개인정보 안내

2026년 10월 16일 기준, 0.6.10 베타의 데이터 처리를 설명합니다. QuotaDock은 자체 회원가입·광고·이용 분석 SDK·사용량 수집 서버를 사용하지 않습니다. AI 로그인과 조회는 해당 공식 서비스와 통신하며, 그 서비스의 데이터 정책도 적용됩니다. [English](PRIVACY_EN.md)

## 저장하는 정보

이 Mac의 앱 설정에 계정을 구분하는 해시 식별자, 플랜, 사용 한도와 확인 시각, 초기화권·혜택의 제공된 내역, 구독 날짜와 짧은 날짜 근거 문구, 사용자가 입력한 금액·메모·알림 일정과 설정을 저장합니다. CLI 실행 파일 경로도 로컬 설정에 보관합니다. 계정 구분에 필요한 원본 이메일·조직 ID 등은 조회 과정에서 해시로 변환하며 원본을 앱 설정에 보관하지 않습니다.

성공한 한도 관측은 최대 90일·30,000회로 제한합니다. 알림 목록은 저장 시 최근 60개를 보관하지만, 중복 방지 정보와 마지막 조회 상태·초기화 일정·구독 메모에는 같은 90일 자동 삭제 규칙이 적용되지 않습니다.

## 로그인 세션

앱 전용 웹 창에서 공식 사이트에 로그인하면 WebKit이 서비스별 별도 프로필에 쿠키·웹 저장 데이터·캐시를 보관할 수 있습니다. 비밀번호는 공식 웹 화면에 입력하며 앱이 로그인 폼의 값을 읽거나 자체 서버로 전송하지 않습니다. Chrome의 로그인 쿠키를 가져오지 않습니다. CLI는 자체 인증 갱신·캐시·로그를 관리할 수 있으며 앱의 연결 해제는 CLI 로그아웃이 아닙니다.

## 선택적인 토큰 집계

기능을 켜면 이 Mac의 Codex·Claude JSONL과 Grok Build의 usage/summary 메타데이터를 제한된 범위로 읽습니다. Codex·Claude 로그 파일에는 대화가 함께 들어 있을 수 있습니다. 파서는 숫자·날짜·중복 제거에 필요한 식별자만 집계하고 대화 텍스트를 앱 기록에 저장하거나 업로드하지 않습니다. 집계 결과와 파일 지문은 메모리에만 보관하며 기능을 끄거나 앱을 종료하면 사라집니다. 여러 로컬 프로젝트·계정이 함께 집계될 수 있습니다.

## 내보내기와 피드백

JSON 백업은 암호화되지 않습니다. 계정 식별자·날짜·금액·관측 이력이 포함되므로 공개 게시·이슈 첨부에 사용하지 마세요. 백업에서는 짧은 웹 근거 문구도 제외합니다. 캘린더 파일은 사용자가 선택한 미래 일정 데이터를 외부 캘린더에 가져올 수 있는 파일입니다.

피드백은 자발적으로 제공하며 자동 전송하지 않습니다. GitHub의 공개 이슈에 작성하면 다른 사람도 볼 수 있습니다. 이메일·계정 ID·토큰·쿠키·결제 내역·대화·원본 로그·백업을 보내지 마세요. 해당 게시처의 데이터 정책도 적용됩니다.

## 연결 해제와 삭제

AI를 연결 해제해도 마지막 조회와 저장된 일정·이력은 남습니다. 앱을 휴지통으로 옮기는 것만으로 설정과 웹 세션이 모두 삭제되지는 않습니다. 베타에는 모든 로컬 데이터와 웹 세션을 한 번에 지우는 버튼이 없습니다. 웹 세션은 각 공식 웹 창에서 로그아웃할 수 있으며 CLI 인증은 해당 CLI에서 관리합니다.

로컬 앱 설정을 비우려면 앱을 종료한 뒤 본인이 터미널에서 `defaults delete local.quotadock.app`을 실행할 수 있습니다. 이 작업은 한도 이력·구독 기록·앱 설정을 삭제하며 복구가 필요하면 먼저 개인적으로 백업하세요. 웹 프로필과 CLI 인증·로그는 삭제하지 않습니다. 이전 QuotaPilot 프로토타입을 쓴 Mac에서는 구 도메인에서 기록을 다시 가져올 수 있으므로 별도 안내가 필요합니다.
