# QuotaDock beta feedback

Feedback is optional and never sent automatically. Use Issues in the GitHub repository where you downloaded the release. For a package shared locally, send just these answers to the person who shared it. [한국어](FEEDBACK.md)

## Installation or query issue

- macOS version and Apple Silicon model family:
- Step: download / first launch / connect CLI / web sign-in / query / notification
- Provider and CLI version:
- Expected behavior:
- Actual behavior and error wording:

Do not include account IDs, emails, tokens, cookies, renewal dates, prices, conversations, backups or raw CLI logs. Screenshots are optional and must be redacted. If the Mac restarts unexpectedly or the app repeatedly crashes, stop testing and report the time, macOS version and step first.

## After 7 and 14 days

- Have you recently opened the app or checked the menu bar? Yes / No
- Which functions did you actually use: quotas, subscription dates, saved resets or reminders?
- Did the planning features help with a decision? Explain without private dates or prices.
- What was the biggest inconvenience?
- Would you continue using it? Yes / No / Unsure

Downloads, stars and positive reactions are not treated as retained users. We use reported installation success, continued use and concrete planning experiences. Public quotation of feedback requires separate author consent.
