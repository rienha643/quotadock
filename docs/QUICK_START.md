# QuotaDock 시작 안내 0.6.10

QuotaDock은 Codex·Claude·Grok의 남은 한도와 구독 날짜를 함께 확인하는 macOS 앱입니다. 이번 무료 베타는 Apple Silicon과 macOS 14 이상을 대상으로 합니다. [English guide](QUICK_START_EN.md)

## 설치

이미 사용 중이면 앱을 종료하고 Applications 폴더의 앱을 새 버전으로 교체합니다. 기존 계정 연결과 로컬 기록은 유지됩니다.

1. 다운로드한 ZIP을 풀고 `QuotaDock.app`을 Applications 폴더로 옮깁니다. 이전 버전이 실행 중이면 먼저 앱 메뉴에서 종료합니다.
2. 앱을 실행합니다. 이 베타는 임시 서명본이며 Apple의 Developer ID 서명·공증을 받지 않았습니다. 다른 Mac에서는 보안 경고가 나타날 수 있습니다.
3. 출처와 SHA-256을 확인하고 실행을 선택한 경우에만 Apple의 [미확인 개발자 앱 안내](https://support.apple.com/en-us/102445)를 따릅니다. 한 번 실행을 시도한 뒤 시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기를 사용할 수 있는 환경이 있습니다. 관리되는 Mac에서는 허용되지 않을 수 있습니다.
4. ‘손상됨’·‘컴퓨터를 손상시킴’ 경고가 나오면 실행을 멈추고 공식 다운로드의 체크섬과 오류 문구를 확인해 주세요. 보안 기능 전체를 끄거나 터미널로 검역 정보를 제거하도록 요구하지 않습니다.

설치할 Mac에 앱 설정·로그인·원본 로그가 포함되지 않은 패키지입니다. 다른 Mac에서 인터넷 다운로드 후 처음 실행하는 경로는 베타 참가자의 검증이 필요합니다.

## AI 연결

공식 Codex CLI, Claude Code, Grok Build 중 사용하는 도구를 자신의 구독 계정으로 로그인해 둡니다. 첫 실행 시 설치된 Codex·Claude CLI를 탐색하고 조회를 시도할 수 있습니다. `연결·설정`에서 사용할 AI를 연결하고, 사용하지 않는 AI는 `연결 끊기`로 제외합니다. CLI가 다른 경로에 있으면 `연결 방법·실행 파일`에서 경로를 지정합니다. 웹 구독만 있고 CLI가 설치되지 않은 환경은 한도 자동 조회를 시작할 수 없습니다.

개인 구독 계정 중심의 베타입니다. Claude 개인 Pro·Max, Grok Build의 공유 구독 한도 응답 등 현재 어댑터가 해석할 수 있는 계정만 지원합니다. API 키·기업 계정과 모든 플랜의 지원을 보장하지 않습니다. 연결 실패 시 공식 CLI의 로그인 상태·버전과 앱의 오류 문구를 확인합니다. 앱의 연결 해제는 공식 서비스의 로그아웃·구독 해지가 아닙니다.

Codex는 기본 5분, Claude·Grok은 15분마다 조회합니다. 실패하면 간격을 늘리고 오프라인·절전 중에는 조회를 멈춥니다. 새로고침은 15초 간격으로 제한합니다. 실패 시 마지막 성공 값과 확인 시각을 유지합니다.

## 메뉴 막대와 언어

`연결·설정 → 상단바 표시`에서 주·5h·월 표시를 켜거나 끄고, AI별로 5시간·주간·Fable 등 표시할 한도를 선택합니다. 정상 조회한 연결만 메뉴 막대에 표시하며 연결이 없으면 QuotaDock 아이콘을 표시합니다. 숫자는 잔여율입니다. 미제공은 0을 의미하지 않습니다. 오래된 값과 실패 안내는 팝업의 상태·확인 시각에서 확인하며 `~` 접두사는 사용하지 않습니다.

`언어 / Language`에서 한국어·English·시스템 설정 따름을 선택합니다. 대시보드 창을 닫아도 메뉴 막대에서 동작하며 `⌘1`로 대시보드를 다시 열 수 있습니다. 종료는 앱 메뉴 또는 메뉴 막대 팝업에서 선택합니다.

## 구독 날짜와 재구독 검토

`구독 검토 → 구독 날짜 연결`에서 공식 웹 창에 로그인하고, 조회한 계정이 연결된 CLI 계정과 같은지 확인하면 날짜가 저장됩니다. Chrome 로그인은 복사하지 않습니다. 날짜는 이 창을 열어 조회하는 방식이며 백그라운드에서 매일 결제일을 자동 재확인하지 않습니다. 날짜 수동 입력은 제공하지 않으며 금액·자동 갱신 상태는 직접 기록합니다.

정상 조회한 유료 주간 초기화는 계정·플랜별로 보관합니다. 연결을 끊어도 마지막 일정은 남습니다. `구독 정보·검토 알림`에서 재구독 검토 시각을 정할 수 있습니다. 지난 초기화 시각을 임의로 매주 연장하지 않으며 구독 해지·결제·재구독은 공식 서비스에서 직접 진행합니다. 저장된 일정은 현재 이용 가능 여부나 절약액을 보장하지 않습니다.

주간 초기화와 결제일은 함께 표시합니다. 차이가 해당 주기보다 크면 차이 문구만 숨깁니다. 웹 결제일은 날짜 기준으로 비교하며 실제 결제 시각을 만들어 표시하지 않습니다.

## 초기화권과 알림

Codex는 공식 조회 응답이 제공하는 초기화권 내역을 표시합니다. Claude는 `혜택·초기화권 → 초기화권 조회`에서 공식 사용량 화면을 읽고 같은 계정을 확인해 저장합니다. Claude 초기화권 조회는 한도 자동 갱신과 별개이며, Grok 초기화권 보유량은 미지원입니다. 초기화권을 사용하는 버튼·API는 앱이 실행하지 않습니다.

같은 한도의 잔여량이 충분히 증가하면 회복 알림을 만듭니다. 조회 간격이 짧을 때는 예정 전 회복과 정기 초기화를 구분하며, 긴 공백 뒤에는 회복 시각·사유를 단정하지 않는 안내를 표시합니다. 서비스 전체의 일괄 초기화인지는 판별하지 못합니다.

저장된 결제일의 3일·1일 전 검토 알림과 앱 내부 재구독 검토 알림을 설정할 수 있습니다. macOS 배너는 `연결·설정 → macOS 시스템 알림 사용`에서 허용합니다. `5초 뒤 테스트 알림`으로 확인합니다. 집중 모드·앱별 알림·화면 공유 설정이 배너를 숨길 수 있습니다. 앱이 전달 완료를 확인해도 배너를 직접 보았다는 뜻은 아닙니다.

## 기록과 데이터

`관측 기록 → 토큰 기록`의 로컬 토큰 집계를 켜면 이 Mac의 Codex·Claude·Grok Build 도구 기록을 읽습니다. 재시작만으로 다시 집계하지 않으며 다음 실행은 `토큰 기록 새로고침`을 누릅니다. 보호 한도로 일부 파일·최근 구간만 집계할 수 있습니다. 합계는 웹·모바일·다른 Mac의 전체 사용량 또는 구독 한도 차감량이 아닙니다. 반복 조회로 아직 확인하지 않은 파일을 추가하면 새 사용 없이도 부분 합계가 증가할 수 있습니다.

`일정·데이터 보관`에서 캘린더 ICS와 JSON 백업을 내보냅니다. 백업은 암호화되지 않으며 계정 식별자·구독 날짜·금액·관측 기록을 포함하므로 공개하지 마세요. 로그인·대화·토큰 원본·CLI 경로는 내보내지 않습니다. 기존 메모·금액과 충돌하는 값은 복원하지 않습니다. 누락된 웹 출처는 기존 날짜와 일치할 때 복원합니다. 다른 Mac에서는 AI 연결·macOS 알림 권한을 별도로 설정합니다.

## 0.6.10 수정

Grok의 주간 초기화 후 사용률 0% 필드가 생략되는 경우를 처리해 잔여량을 표시합니다. 공유 과금과 유효한 현재 기간이 확인되는 응답만 100%로 해석하며, 명시적 null·불완전한 기간은 계속 미확인으로 표시합니다.
